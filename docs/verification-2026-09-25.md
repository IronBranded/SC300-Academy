## Method

- **Source file (99):** the Learn URL was mapped to its source file in Microsoft’s public docs repository (entra-docs, windowsserverdocs, security, microsoft-365-docs, microsoft-graph-docs-contrib, microsoftgraph-docs-powershell) and fetched from raw.githubusercontent.com. A 200 response means the page is published at that URL; anchors were checked against the file’s headings; the title comes from the file’s front matter. Moved pages were resolved through each repository’s .openpublishing.redirection.json.
- **Live page (33):** repositories that are not public (Defender for Cloud Apps, Windows client, Learn training and credentials) and Microsoft Security blog posts were confirmed by fetching the exact URL or by the exact en-us URL appearing in a web search result during the run.
- **HTTP GET (1):** GitHub repository reachable.
